# Documentación de CGame++

Bienvenido a la documentación oficial de **CGame++**, un framework 2D en C++20 con renderizado Vulkan e inspiración en la API de pygame.

| [Ejemplos](ejemplos.md) | Análisis de Flappy Bird y Pong, y patrones de uso. |

## Primeros pasos

1. Compila el proyecto siguiendo [instalacion.md](instalacion.md).
2. Ejecuta `./build/flappy_bird` o `./build/pong`.
3. Revisa el [inicio rápido del README](../README.md#inicio-rápido).
4. Consulta la [referencia de la API](api.md) para crear tu propio juego.
